Advanced React Patterns: Custom Hooks & Context

August 12, 2026 By Tech Writers 12 min read

Introduction

React has evolved significantly with the introduction of Hooks in version 16.8. Advanced patterns like custom hooks and Context API allow you to build more scalable and maintainable applications. This guide explores these powerful patterns in depth.

Custom Hooks: Reusing Logic

Custom hooks are JavaScript functions that use React hooks internally. They let you extract component logic into reusable functions.

// useWindowWidth custom hook
function useWindowWidth() {
    const [width, setWidth] = useState(window.innerWidth);

    useEffect(() => {
        const handleResize = () => setWidth(window.innerWidth);
        window.addEventListener('resize', handleResize);
        return () => window.removeEventListener('resize', handleResize);
    }, []);

    return width;
}

// Usage in component
function MyComponent() {
    const width = useWindowWidth();
    return <p>Window width: {width}px</p>;
}

Context API for State Management

The Context API provides a way to pass data through the component tree without having to pass props down at every level. It's perfect for themes, authentication, and user preferences.

// Create context
const ThemeContext = React.createContext();

// Provider component
function ThemeProvider({ children }) {
    const [theme, setTheme] = useState('light');
    
    const toggleTheme = () => {
        setTheme(prev => prev === 'light' ? 'dark' : 'light');
    };

    return (
        <ThemeContext.Provider value={{ theme, toggleTheme }}>
            {children}
        </ThemeContext.Provider>
    );
}

// Custom hook to use context
function useTheme() {
    return useContext(ThemeContext);
}

Performance Optimization

When using Context API, remember that any change to the context value will cause all consumers to re-render. Use useMemo and useCallback to optimize performance:

function ThemeProvider({ children }) {
    const [theme, setTheme] = useState('light');
    
    const toggleTheme = useCallback(() => {
        setTheme(prev => prev === 'light' ? 'dark' : 'light');
    }, []);

    const value = useMemo(
        () => ({ theme, toggleTheme }),
        [theme, toggleTheme]
    );

    return (
        <ThemeContext.Provider value={value}>
            {children}
        </ThemeContext.Provider>
    );
}
